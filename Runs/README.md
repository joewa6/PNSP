# Runs Directory

**Immutable run outputs organized by run_id across pipeline stages A→D.**

## Principles

- **Data is run-scoped** - Each run gets a unique directory
- **Stages write to their namespace** - No cross-contamination
- **Traceable provenance** - run_id encodes timestamp, config, git commit
- **Stage boundaries are explicit** - Clear input/output contracts

## run_id Format

Encodes key metadata in directory name:

```
<timestamp>__<charge_state>__<ligand_set>__git-<commit>

Example:
2026-01-14T16-05-12Z__c50__ligset-PETv1__git-a1b2c3d
```

Components:
- **timestamp**: ISO 8601 format (UTC)
- **charge_state**: NP charge (c35, c50, etc.)
- **ligand_set**: Input dataset identifier
- **git commit**: Short hash for code provenance

## Stage Contracts

### Stage A → Stage B

**Stage B reads:**
- `run_manifest.json` → list of systems
- For each system: `stageA/systems/<ligand_id>/system.{prmtop,inpcrd}`

**Stage B writes:**
- `stageB/status.json`
- `stageB/simulations/<ligand_id>/...`
- Updates `run_manifest.json` with simulation results

### Stage B → Stage C

**Stage C reads:**
- `run_manifest.json` → list of completed simulations
- `stageB/simulations/<ligand_id>/traj/*`

**Stage C writes:**
- `stageC/status.json`
- `stageC/archive_pointer.json` (HPC location)
- Updates `run_manifest.json`

### Stage C → Stage D

**Stage D reads:**
- `run_manifest.json` → archive locations
- `stageC/archive_pointer.json`

**Stage D writes:**
- `stageD/status.json`
- `stageD/outputs/tables/*`
- `stageD/outputs/figures/*`
- Updates `run_manifest.json` with final metrics

## CLI Interface

All stages accept:

```bash
# Stage A (creates run)
python Orchestra/stageA_builder/src/build.py \
  --csv Inputs/stageA/ligands/PET_screening_v1.csv \
  --np-profile Inputs/stageA/nanoparticle/NP_profile_c50.yaml \
  --run-root Runs/PET_SCREENING/ \
  --run-id <auto-generated>

# Stages B/C/D (consume run)
python Orchestra/stageX/src/process.py \
  --run-dir Runs/PET_SCREENING/<run_id>
```

## Smoke Tests

End-to-end tests go under `__SMOKE__/`:

```
Runs/__SMOKE__/
└── 2026-01-14T16-12-00Z__tiny__git-a1b2c3d/
    └── (same structure as production runs)
```

- Use minimal inputs (3-5 molecules)
- Full A→D pipeline
- Verifies end-to-end integration
- Not for unit tests (those go in `tests/`)

## What Does NOT Belong Here

- ❌ Stage code (goes in `Orchestra/`)
- ❌ Unit test fixtures (goes in `tests/fixtures/`)
- ❌ Input definitions (goes in `Inputs/`)
- ❌ Temporary scratch files (clean up after stage completes)
